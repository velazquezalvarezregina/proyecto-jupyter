Pronóstico de ventas mensuales con ARIMA

Modelo ARIMA(1,1,1) aplicado a datos simulados de ventas mensuales.

Objetivo

Aplicar un modelo ARIMA para estudiar una serie temporal de ventas y generar un pronóstico de seis meses, además de comprobar el desempeño con datos reservados.

Los datos son simulados y el pronóstico es una estimación, no una garantía de ventas futuras.

¿Qué significa ARIMA(1,1,1)?

  • p = 1: componente autorregresivo de orden 1.
  • d = 1: una diferenciación de la serie.
  • q = 1: componente de media móvil de orden 1.

Comprobación del modelo

Se reservaron seis meses para comparar las ventas observadas con las predicciones sin utilizarlos durante el entrenamiento.

Pronóstico de seis meses

Después de la comprobación, se ajustó el modelo con todos los datos y se proyectaron seis meses nuevos.

Conclusión

ARIMA(1,1,1) permite generar una proyección a partir del comportamiento temporal de los datos. La comprobación con meses reservados ayuda a observar la diferencia entre estimaciones y valores reales. La predicción debe interpretarse con cautela porque existe incertidumbre y los datos del ejercicio son simulados.
